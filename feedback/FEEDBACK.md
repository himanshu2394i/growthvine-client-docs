# Feedback on this skill

Triggered when the advisor says "feedback", reports a problem with how you
worked, or suggests a change. Afterwards, go back to where you were.

## Ask (2-3 questions, short)

1. What happened, or what would you like changed?
2. What did you expect instead?
3. How much does it matter? (low / medium / high)

Work out the rest yourself: which document type and which step you were in.

## Draft the note

```
Skill version: <from SKILL.md>
Document type: <proposal / assessment / fund / category / market / other>
Step: <questions / sections / display / brief / build / check / delivery>
What happened: <advisor's words, lightly tidied>
Expected: <advisor's words>
Matters: <low / medium / high>
```

**Remove all client data before showing it.** No client or RM names, amounts,
holdings, fund names tied to this client, or file names. Describe the shape
instead: "a 12-holding proposal with 4 buckets and 2 options".

Show the note and ask the advisor to confirm it.

## Send

Form link: FEEDBACK_FORM_URL

- If the link above is still `FEEDBACK_FORM_URL` (not set up yet): ask the advisor
  to copy the note and send it to the person who maintains this skill.
- Otherwise: give the link and say "Paste the note into the form, one field per
  line."

Never send anything yourself.
